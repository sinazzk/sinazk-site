CASE STUDY 05 · 2019 · SOCIAL & LOCATION

SOK SOK

A location-based messaging app with a touch of gamification: pin a message to a place, and only your friend standing there can read it.

ROLE
Product designer: branding, UX and UI
CLIENT
T-Lab, Tehran Urban Innovation Center
TIMELINE
2 years, from research to funded prototype
RESULT
Received a grant for development
AT A GLANCE

Problem. Location-bound, time-limited messages work nothing like a normal chat app. People need to see where and how long their messages last, and find old ones later.

What I did. Defined an early-adopter persona, mapped task flows, and tested several interface concepts with paper prototypes before settling on a map-first design.

Outcome. The project, run as “Non-Infrastructured Network”, received a grant for development. It wound down shortly after development was finished.

DETAIL 01 · CONTEXT·SHEET 01/03

Messages you have to go somewhere to read

SOK SOK is a location-based communication network. Users pin messages for friends at a specific place, to be found only in that vicinity, and messages can expire before they are deleted forever.

It was developed with T-Lab at the Tehran Urban Innovation Center as “Non-Infrastructured Network”, and received a grant for development.

PARTNER
T-Lab, Tehran Urban Innovation Center
RESULT
Development grant
DETAIL 02 · THE PROBLEM·SHEET 02/03

Every message has a place and a timer

Each message has a location it can be viewed in and a time limit. Users need to see the location and timer of their active messages at a glance, and all previous messages from each friend need to be stored to read later.

PERSONA
Early adopter: student, social, tech-savvy gamer
DETAIL 03 · THE SOLUTION·SHEET 03/03

Map first, then a calm inbox

Process maps defined the task flows, and paper prototypes let us test several directions quickly. On launch you see a map and a pin: move it, write a message, then choose the recipient, the location radius and how long it stays readable.

To keep the map uncluttered, a separate page collects every message from each contact in order, each one only readable if you reached its location in time.

METHODS
Process maps · service blueprint · paper prototyping
CONTROLS
Recipient · radius · time limit
